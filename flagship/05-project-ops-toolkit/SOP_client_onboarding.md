# SOP: New Client Onboarding (Virtual Assistant / Project Coordinator)

**Purpose:** every new client is set up the same way within 2 working days.
**Owner:** Project coordinator · **Review:** every 6 months

| # | Step | Tool | Done when |
|---|---|---|---|
| 1 | Send welcome e-mail with intake form link | Gmail template · Google Forms | Form submitted |
| 2 | Create client folder from template (`/Clients/<Name>/01_Contract, 02_Input, 03_Working, 04_Delivered`) | Google Drive | Folder shared with client (view only on 04) |
| 3 | Copy `project_tracker.xlsx`, fill tasks and dates from the agreed scope | Sheets / Excel | Kick-off date set, owners assigned |
| 4 | Fill RACI tab and confirm with client | Sheets | Client replies "approved" |
| 5 | Book kick-off call (30 min) and send agenda 24 h before | Calendar | Invite accepted |
| 6 | After kick-off: log actions in *Actions* tab and send summary within 2 h | Gmail | Summary sent |
| 7 | Set weekly status reminder (Friday 15:00) and run `status_report.py` | Calendar · Python | First report sent |

**Quality checks:** no client data in personal accounts · file names `YYYYMMDD_client_document_v01` · every deliverable versioned.

**Templates:** welcome e-mail, kick-off agenda, weekly status (generated), close-out checklist.
