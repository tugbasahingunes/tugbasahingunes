# 09 · Landing Page / Simple Website (HTML · CSS)

**Client problem:** "I need a one-page site for my service that looks good on phones and brings in enquiries."

`index.html`: a single-file, dependency-free landing page for a fictional tutoring service:
- Mobile-first responsive layout (CSS grid, media queries)
- Clear hero + call-to-action, service cards, 3-step process, enquiry form
- SEO basics (title, meta description, semantic headings, `lang="tr"`), accessible labels
- Loads instantly: no frameworks, no images to download

Open it directly in a browser or publish free with **GitHub Pages**. Form can be connected to Formspree / Google Forms / WhatsApp. WordPress, Wix and Carrd set-ups also offered.
